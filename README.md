# Perfect Place 

Адаптивный лендинг для сервиса бронирования отелей.

## О проекте
Проект представляет собой современную страницу (Landing Page) с адаптивным дизайном под мобильные устройства и ПК (Mobile-first подход). 

## Технологии
* **HTML5** (Семантическая разметка)
* **Tailwind CSS** (Стилизация)

## Как запустить
1. Скачайте или склонируйте проект.
2. Откройте файл `index.html` в любом современном браузере.
3. (Опционально) Если планируете менять стили Tailwind, запустите компилятор: 
   `npx tailwindcss -i ./src/input.css -o ./src/output.css --watch`

## Структура
* `index.html` — главная страница.
* `images/` — папка с картинками.
* `src/output.css` — готовые стили.
