# Perfect Place 

Полный адаптивный лендинг для сервиса поиска и бронирования отелей.

## О проекте
Сайт содержит все основные блоки для гостиничного бизнеса:
* **Hero-секция** с главным заголовком и презентационным видео.
* **Популярные отели** с ценами, адресами и рейтингом.
* **Удобства отеля** (Facilities) в виде аккуратной сетки иконок.
* **Блок истории** компании и отзывы реальных клиентов.
* **Интерактивная форма** подписки на обновления с абсолютным позиционированием.

## Технологии
* **HTML5** (Семантическая структура макета)
* **Tailwind CSS** (Кастомные стили через произвольные значения `[]`)

## Как запустить проект
1. Скачайте или склонируйте архив с проектом.
2. Откройте файл `index.html` в браузере (двойным кликом или через Live Server в VS Code).
3. Для отслеживания изменений в Tailwind используйте команду:
   `npx tailwindcss -i ./src/input.css -o ./src/output.css --watch`

## Структура файлов
* `index.html` — разметка всех секций сайта.
* `output.css` — скомпилированные стили Tailwind CSS.
* `images/` — графические ресурсы, иконки и изображения отелей.
